# AniSphere — *Your World. Your Anime.*

A premium, production-grade Flutter app for anime fans — the anime equivalent of
**Instagram + TikTok + Discord + Letterboxd** in one platform. Dark-only, gradient-rich,
fully localized (8 languages incl. RTL Arabic), and built with a clean feature-first
architecture.

> Built with Flutter 3.16+, Riverpod, GoRouter, Google Fonts, fl_chart, flutter_animate.

---

## ✨ What's inside

**25+ screens**, all filled with real anime data (no lorem ipsum, no grey boxes):

| Area | Screens |

## 🚀 Getting started

> This repo ships the complete Dart app (`lib/`), `pubspec.yaml`, and the
> platform permission files. The rest of the native scaffolding (Gradle wrapper,
> Xcode project, `MainActivity`, etc.) is generated by Flutter and **not** checked in.

```bash
# 1. From the project root, generate the native android/ & ios/ scaffolding.
#    flutter create does NOT overwrite the existing lib/, pubspec.yaml,
#    AndroidManifest.xml or Info.plist — it only fills in what's missing.
flutter create --org com.anisphere --project-name anisphere .

# 2. Fetch dependencies
flutter pub get

# 3. Run on a device / simulator
flutter run
```

Requires the **Flutter 3.16+ stable** SDK and Dart 3.2+.

> **Fully offline typography** — Outfit & Space Grotesk ship as vendored variable
> TTFs in `assets/fonts/` (registered in `pubspec.yaml`), so there's no `google_fonts`
> runtime fetch. If the files ever go missing, re-fetch with `tool/fetch_fonts.sh`.

### Optional: app icon & splash

Drop the PNGs described in [`assets/icons/README.md`](assets/icons/README.md), then:

```bash
dart run flutter_launcher_icons
dart run flutter_native_splash:create
```

## 🏛 Architecture

Feature-first, with a shared design system and Riverpod state:

```
lib/
├── main.dart                 # bootstrap (Hive, timeago, system chrome)
├── app.dart                  # MaterialApp.router + locale/RTL
├── core/
│   ├── constants/            # colors, gradients, text styles, strings (8 langs)
│   ├── theme/                # dark ThemeData
│   ├── router/               # GoRouter (StatefulShellRoute + pushed routes)
│   └── utils/                # haptics, formatters
├── data/
│   ├── models/               # user, anime, post, message, card
│   └── sample_data.dart      # all demo content
├── features/<feature>/       # one folder per screen area
└── shared/
    ├── widgets/              # reusable UI kit
    └── providers/            # language, user, currency, aniscan
```

- **State:** Riverpod `StateNotifier`s — `userProvider`, `currencyProvider`,
  `languageProvider`, `aniScanProvider`.
- **Navigation:** GoRouter. The 4 tabs (Feed / Discover / Community / Profile) live in a
  `StatefulShellRoute.indexedStack`; everything else is a full-screen pushed route.
- **Persistence:** `SharedPreferences` (language choice, AniScan lifetime counter) + Hive
  initialized for future use.

## 🎨 Design system

Defined in `core/constants/`:

- **Palette** — deep-space navy `#0D0F1A`, electric purple `#8B5CF6`, sakura pink
  `#F472B6`, neon cyan `#22D3EE`, AniGold `#F59E0B`, AniGem `#10B981`.
- **Type** — Outfit for UI, Space Grotesk for numbers/stats.
- **Currencies** — `AniGoldIcon` (radial-gold coin with `∞`) and `AniGemIcon`
  (CustomPaint faceted gem) are always visually distinct.
- **Aura glow** — `UserAvatar` glows per level; Otaku Elite shimmers purple, Weeb God
  cycles a rainbow/gold hue (animated).

## 🌍 Localization & RTL

`languageProvider` holds the active code; `AppStrings` maps keys per language —
**all 8 languages are fully translated (128 keys each: EN, AR, JA, KO, ES, FR, TR, ID)**,
with English as the safety fallback. Use `ref.tr('key')` in widgets. Selecting **Arabic**
flips the entire app to RTL via a `Directionality` wrapper in `app.dart`.

## 💎 AniPlus & AI gating

`isPlusProvider` drives premium gating. AI/premium features show a 💎 lock that opens
`showAniPlusPaywall(...)`. **AniBot is always free.** **AniScan** allows 3 lifetime free
scans (tracked in `SharedPreferences`) before the paywall. The demo user starts as a
Plus subscriber — toggle it from the Wallet → AniPlus tab.

## 📝 Demo notes

- **Real video playback:** the **Ani Videos** vertical feed plays actual MP4s via
  `video_player` (autoplay on the active page, muted + looping, tap-to-pause, mute toggle),
  and the **AMV** tab opens a full `chewie` player with a scrubber and fullscreen. Demo
  clips point at stable Flutter-hosted sample MP4s in `_kVideoUrls` — swap for your CDN.
  The gradient + emoji surface stays behind the video as an offline/poster fallback.
- **Visuals over assets:** characters/posters are gradient + emoji compositions (per the
  "no grey placeholders" rule), so the app needs no bundled artwork beyond the fonts.
- All data is hardcoded in `data/sample_data.dart`.
